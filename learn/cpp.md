# 헤더 파일에 포함하는 것

헤더 파일에는 인터페이스에 보이는 것만 추가한다.  
예를 들어, 아래의 코드에서 VL530X 인터페이스를 활용하고 싶다고 하자.  
그러면 사용자에게 보이는 건 그걸 래핑한 함수일 뿐 다른 것들은 보일 필요가 없기에 cpp파일 안에 넣어주고 헤더에는 필요한 함수만 남긴다.  
이때 필요한 함수에서 의존적으로 사용하는 라이브러리의 헤더파일만을 헤더파일에 포함한다.  
아래의 코드에서는 `uint16_t`를 알려줘야 하기 때문에 `Arduino.h`파일을 포함시켜줬다.

```cpp
// sensor.h
#include <Arduino.h>

uint16_t sensorReadDistanceMm();  // ← uint16_t 가 뭔지 알려면 Arduino.h (또는 cstdint) 필요
```

# ifndef의 역할

여러 파일에서 같은 헤더 파일을 참조할 때, 헤더파일이 한번만 참조되도록 하는 일종의 표시 같은 것이다.

```cpp
#ifndef SENSOR_H
#define SENSOR_H
// 여러 선언들
#endif
```
# uint16_t
부호 없는 16비트 정수 타입.  
VL530X에서 거리센서가 반환하는 값.
