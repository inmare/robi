# 적재함 — 아두이노 우노 핀맵

우노 위에 SZH-ET004 CNC 쉴드, A4988 4개 꽂힌 상태.  
STEP·DIR·EN은 쉴드가 이미 이어 줌. 모터·센서·스위치 선은 쉴드 헤더에 바로 꽂음.

코드 `AccelStepper lift(AccelStepper::DRIVER, 2, 5)` = 쉴드 X축. Enable은 D8, LOW면 켜짐.

| 쉴드에서 꽂는 곳 | 아두이노 | 역할 |
|---|---|---|
| X 모터 4핀 | D2 STEP, D5 DIR | 리프트 KH42JM2-901 |
| Y 모터 4핀 | D3 STEP, D6 DIR | 푸셔 17HS4401 |
| Z 모터 4핀 | D4 STEP, D7 DIR | 안 씀 |
| A 모터 4핀 | D12 STEP, D13 DIR | 안 씀 |
| (공통, 전선 없음) | D8 EN | 드라이버 4개 같이. LOW=켜짐 |
| END STOPS `X-` | D9 | 리프트 하단 리미트 |
| END STOPS `Y-` | D10 | 리프트 상단 리미트 |
| END STOPS `Z-` | D11 | 푸셔 후진 리미트 (4개일 때) |
| `Abort` | A0 | 푸셔 전진 리미트 (4개일 때) |
| I2C `SDA` | A4 | VL53L0X D |
| I2C `SCL` | A5 | VL53L0X C |
| I2C / END STOPS `+` | 5V | 센서·스위치 전원 |
| I2C / END STOPS `-` | GND | 공통 GND |
| 파란 나사 단자 + | — | 모터 12V + |
| 파란 나사 단자 − | — | 모터 12V −, 우노 GND와 공통 |

USB는 우노·쉴드 로직만. 모터 12V를 VIN에 넣지 말 것. D0/D1은 USB 시리얼이라 전선 꽂지 말 것.

```
  D13  A축 DIR (안 씀)
  D12  A축 STEP (안 씀)
  D11  END STOPS Z-  푸셔 후진
  D10  END STOPS Y-  리프트 상단
   D9  END STOPS X-  리프트 하단
   D8  EN (LOW=켜짐)
   D7  Z축 DIR (안 씀)
   D6  Y축 DIR  푸셔
   D5  X축 DIR  리프트
   D4  Z축 STEP (안 씀)
   D3  Y축 STEP 푸셔
   D2  X축 STEP 리프트
   D1  TX 꽂지 말 것
   D0  RX 꽂지 말 것
  A0   Abort    푸셔 전진 (4개일 때)
  A1   Hold     예비
  A2   Resume   예비
  A3   CoolEn   예비
  A4   I2C SDA  VL53L0X D
  A5   I2C SCL  VL53L0X C
```

# 적재함 — A4988 (CNC 쉴드)

드라이버는 이미 소켓에 있음. STEP/DIR/VDD/GND/RESET/SLEEP은 안 건드림.

리프트 = X 자리, 푸셔 = Y 자리. Z·A는 꽂혀 있어도 모터 선만 안 꽂으면 됨.

## 모터 선 (X / Y 옆 4핀)

실크는 `1A 1B 2A 2B` 또는 `A+ A- B+ B-`.

| 쉴드 핀 | KH42JM2-901 (X, 리프트) | 17HS4401 (Y, 푸셔) |
|---|---|---|
| 1A | 코일 1 한쪽 | 코일 1 한쪽 |
| 1B | 코일 1 다른쪽 | 코일 1 다른쪽 |
| 2A | 코일 2 한쪽 | 코일 2 한쪽 |
| 2B | 코일 2 다른쪽 | 코일 2 다른쪽 |

KH42는 6선. 코일 양끝 4선만 꽂고 가운데 탭 2선은 어디에도 안 꽂음. GND에도 안 꽂음. 테이프 붙일 것.

6핀이면 저항이 나오는 3개가 같은 코일. 그중 값이 가장 큰 2개가 양끝. 그 쌍을 1A/1B, 나머지 코일 양끝을 2A/2B.

한쪽 코일 두 선만 서로 바꾸면 방향이 반대. 12V는 바꾸지 말 것.

## 전원·전류

파란 나사 단자: 12V 어댑터 + / −. USB만으로는 모터 안 돎.

KH42는 약 1.2A/상, 17HS4401은 약 1.7A/상. A4988은 방열판 있어도 1.2A 근처.  
가변저항으로 제한한 뒤에 돌릴 것. 흔한 0.1Ω 모듈이면 `Vref ≈ 목표전류 × 0.8`. 리프트는 1.0A면 약 0.8V.

마이크로스텝은 각 드라이버 옆 점퍼 3개. 없으면 풀스텝.

# 적재함 — VL53L0X (ToF)

쉴드 I2C 헤더에 꽂음. 우노 A4/A5로 이어져 있음. 우노 핀에 직접 꽂지 말 것.

| VL53L0X | 쉴드 |
|---|---|
| − / GND | I2C GND 또는 END STOPS `-` |
| + / VIN / 5V | I2C 5V 또는 END STOPS `+` |
| C / SCL | I2C SCL (A5) |
| D / SDA | I2C SDA (A4) |

`GPIO1`, `XSHUT`은 꽂지 않아도 됨. XSHUT을 쓸 거면 5V에 올려 두거나 떠 두지 말 것.

# 적재함 — 리미트 스위치 (KW-10R)

스위치는 `C`(공통), `NO`, `NC`.  
`C` → 쉴드 GND (`END STOPS`의 `-`), `NO` → 아래 신호 핀. 우노 내부 풀업. 눌리면 LOW.

`X-`와 `X+`는 같은 아두이노 핀(D9). `Y-`/`Y+`는 D10, `Z-`/`Z+`는 D11.  
한 축의 +/−에 스위치 두 개를 나눠 꽂으면 어느 쪽인지 구분 못 함. + 칸은 비움.

## 2개만 (리프트만)

| 스위치 | 쉴드 | 아두이노 |
|---|---|---|
| 리프트 하단 C | END STOPS `-` | GND |
| 리프트 하단 NO | END STOPS `X-` | D9 |
| 리프트 상단 C | END STOPS `-` | GND |
| 리프트 상단 NO | END STOPS `Y-` | D10 |

푸셔 리미트는 아직 없음. 푸셔는 스텝 수·시간 초과로만 멈춤.

## 4개 (리프트 + 푸셔)

| 스위치 | 쉴드 | 아두이노 |
|---|---|---|
| 리프트 하단 C | END STOPS `-` | GND |
| 리프트 하단 NO | END STOPS `X-` | D9 |
| 리프트 상단 C | END STOPS `-` | GND |
| 리프트 상단 NO | END STOPS `Y-` | D10 |
| 푸셔 후진 C | END STOPS `-` | GND |
| 푸셔 후진 NO | END STOPS `Z-` | D11 |
| 푸셔 전진 C | Abort 옆 GND, 또는 END STOPS `-` | GND |
| 푸셔 전진 NO | `Abort` | A0 |

`Hold`(A1)는 예비. 푸셔 전진을 여기 꽂아도 됨. 그때는 코드도 A1로.

# 이동로봇 — N7960 모터 드라이버 (VLT-MD010) 2개

나사 단자 B, M은 전원·모터. 옆쪽 헤더 8핀은 라즈베리 파이.

드라이버 1개 = 바퀴 1개. 왼쪽·오른쪽 각각 하나씩.

## 나사 단자 (B, M)

- B+: 모터 전원 + (XL4016 출력 +, 약 6V)
- B-: 모터 전원 − (XL4016 출력 −, GND)
- M+: 그 바퀴 모터 전선 한쪽
- M-: 그 바퀴 모터 전선 다른 쪽

B+ / B- 사이에 2200uF를 같이 물림. 커패시터 − 는 B-(GND).  
0.1uF는 드라이버가 아니라 모터 단자에 납땜.

모터가 반대로 돌면 M+ / M- 두 선만 서로 바꿈. B+ / B- 는 바꾸지 않음.

왼쪽 드라이버 B+와 오른쪽 드라이버 B+는 XL4016 +에서 갈라짐. B-도 GND로 모음.

## 신호 핀 (헤더)

RPWM·LPWM은 하드웨어 PWM 핀만 사용. R_EN과 L_EN은 **따로** 꽂음. 같은 GPIO에 묶지 않음.

달리는 바퀴는 그 드라이버의 R_EN, L_EN을 **둘 다 HIGH**. 둘 중 하나만 HIGH면 한쪽 방향만 됨. 정지: PWM 둘 다 0, 또는 EN 둘 다 LOW.

실제 배선이 좌우 반대라, 아래는 **로봇 기준 왼쪽·오른쪽**이다.

| 드라이버 핀 | 역할 | 왼쪽 바퀴 | 오른쪽 바퀴 |
|---|---|---|---|
| RPWM | 한쪽 방향 PWM | GPIO18 (물리 12) | GPIO12 (물리 32) |
| LPWM | 반대 방향 PWM | GPIO19 (물리 35) | GPIO13 (물리 33) |
| R_EN | 한쪽 하프브리지 활성 | GPIO27 (물리 13) | GPIO17 (물리 11) |
| L_EN | 반대 하프브리지 활성 | GPIO21 (물리 40) | GPIO4 (물리 7) |
| R_IS | 전류 알람 | 꽂지 않음 | 꽂지 않음 |
| L_IS | 전류 알람 | 꽂지 않음 | 꽂지 않음 |
| VCC | 드라이버 로직 5V | 물리 4 | 물리 4 (같이) |
| GND | 로직 GND | 물리 14 | 물리 20 |

전진: RPWM에 PWM, LPWM은 0, R_EN·L_EN 둘 다 HIGH  
후진: LPWM에 PWM, RPWM은 0, R_EN·L_EN 둘 다 HIGH

RPWM/LPWM/EN은 전부 파이 GPIO 3.3V. VCC만 5V. 파이 GPIO에 5V를 넣지 말 것.

# 이동로봇 — A3144E 홀 센서 (VLT-ML005) 2개

지금 센서는 **2개**. 왼쪽 바퀴 1개, 오른쪽 바퀴 1개.  
모듈 핀은 보통 `VCC`, `GND`, `DO`, (있으면) `AO`.  
엔코더로 쓰는 건 `DO`만. `AO`는 꽂지 않음.

전원은 **파이 3.3V**에서 공급. 5V로 켜면 DO가 5V가 되어 파이 GPIO가 죽을 수 있음.

자석이 가까우면 DO가 LOW, 없으면 HIGH인 모듈이 많음. 코드에서 떨어지는 순간(하강 에지)을 세면 됨.

`GND`는 파이와 이어진 **공통 GND**. 전용 핀 없음.

| 센서 | 모듈 핀 | 파이 |
|---|---|---|
| 왼쪽 바퀴 | VCC | 물리 17 (3.3V) |
| 왼쪽 바퀴 | DO | GPIO16 (물리 36) |
| 오른쪽 바퀴 | VCC | 물리 1 (3.3V) |
| 오른쪽 바퀴 | DO | GPIO5 (물리 29) |

GPIO20(물리 38), GPIO6(물리 31)은 나중에 방향 판별용 홀2. 지금은 비움.

# 이동로봇 — 리미트 스위치 (KW-10R) · IR

스위치는 보통 `C`(공통), `NO`, `NC`.  
`C` → GND, `NO` → GPIO. 파이 내부 풀업 사용. 눌리면 LOW.

| 부품 | 파이 |
|---|---|
| 왼쪽 주차 리미트 NO | GPIO23 (물리 16) |
| 왼쪽 주차 리미트 C | 물리 25 GND |
| 오른쪽 주차 리미트 NO | GPIO22 (물리 15) |
| 오른쪽 주차 리미트 C | 물리 9 GND |
| IR 브레이크 빔 DO | GPIO24 (물리 18) |
| IR VCC | 모듈이 5V면 물리 4와 같은 5V 버스. DO가 5V이면 분압 |
| IR GND | 물리 34 GND |

# 이동로봇 — 라즈베리 파이 4 전원·기타

- 파이 전원 5V: 5V 5A 컨버터 + → **물리 2**. USB-C로 켜면 물리 2는 비워 둬도 됨
- 파이 전원 GND: 컨버터 − → **물리 6**
- 드라이버 VCC는 **물리 4**만. 물리 2와 겸용하지 말 것
- 6V·20V는 파이 금지
- 모터 GND(B-)와 파이 GND는 반드시 공통
- X4 Pro 라이다: 파이 USB. GPIO 아님

# 이동로봇 — ESP32-CAM (AI-Thinker)

카메라는 모듈에 이미 붙어 있어서 카메라 리본은 그대로 두면 됨.  
파이와는 **전원 + (선택) UART**. 사진·비상정지는 Wi-Fi만으로도 되지만, 비상정지를 전선으로 보내려면 UART를 꽂음.

## 전원 (필수)

파이 5V 핀에서 끌어오지 말 것. 카메라 켜질 때 전류가 커서 파이가 리셋됨.

- ESP32-CAM `5V` → 5V 5A 컨버터 + (파이와 같은 컨버터에서 갈라짐)
- ESP32-CAM `GND` → 컨버터 −, 파이 GND와 공통
- `3V3`에는 외부 5V를 넣지 않음

## 파이 UART (비상정지·명령, 선택)

TX끼리 꽂지 말고 **TX → RX**로 엇갈림.

| ESP32-CAM | 역할 | 라즈베리 파이 |
|---|---|---|
| `U0T` / GPIO1 (TX) | 캠 → 파이 | GPIO15 (물리 10) |
| `U0R` / GPIO3 (RX) | 파이 → 캠 | GPIO14 (물리 8) |
| `GND` | 공통 GND | 물리 9 |

파이에서 시리얼 콘솔을 끄고 이 핀을 UART로 써야 함. GPIO 3.3V끼리라 레벨 변환은 없음.

## 펌웨어 올릴 때 (USB-TTL)

평소 파이 UART와 동시에 쓰지 말 것. 올릴 때만 USB-TTL에 꽂음.

| ESP32-CAM | USB-TTL |
|---|---|
| `5V` | 5V |
| `GND` | GND |
| `U0R` (GPIO3) | TX |
| `U0T` (GPIO1) | RX |
| `GPIO0` | GND에 붙인 채로 리셋 → 업로드 모드. 끝나면 GPIO0 떼기 |

## ESP32-CAM에서 남는 핀

카메라는 아래 GPIO를 이미 씀. 여기에 전선 꽂지 말 것.

`GPIO0, 5, 18, 19, 21, 22, 23, 25, 26, 27, 32, 34, 35, 36, 39`

SD카드를 안 쓰면 아래가 버튼·LED용으로 남음.

| ESP32-CAM 핀 | 용도 |
|---|---|
| GPIO12 | 비상정지 버튼 등 |
| GPIO13 | 예비 |
| GPIO14 | 예비 (SD CLK) |
| GPIO15 | 예비 (SD CMD) |
| GPIO2 | 예비 |
| GPIO4 | 온보드 플래시 LED. 일반 입력으로 쓰기 애매함 |
| GPIO16 | PSRAM. 쓰지 말 것 |

비상정지 버튼을 캠에 다는 경우: 버튼 한쪽 `GPIO12`, 다른 쪽 `GND`. 캠이 Wi-Fi나 UART로 파이에 정지를 보냄.

# 라즈베리 파이 물리 핀 빠른 찾기

USB·이더넷이 있는 변의 **반대쪽** 긴 헤더. 핀 1은 사각형 패드인 **3.3V**. 왼쪽 줄이 홀수, 오른쪽 줄이 짝수. 구멍 세면서 꽂을 것.

  (5) 비움                   (6) GND   파이 전원 GND
  (7) GPIO4   오른 L_EN      (8) GPIO14 파이 TX → 캠 RX
  (9) GND     캠·오른 리미트 (10) GPIO15 파이 RX ← 캠 TX
 (11) GPIO17  오른 R_EN      (12) GPIO18 왼 RPWM
 (13) GPIO27  왼 R_EN        (14) GND   왼 드라이버
 (15) GPIO22  오른 리미트    (16) GPIO23 왼 리미트
 (17) 3.3V    왼홀 VCC       (18) GPIO24 IR DO
 (19) 비움                   (20) GND   오른 드라이버
 (21) 비움                   (22) 비움
 (23) 비움                   (24) 비움
 (25) GND     왼 리미트      (26) 비움
 (27) 꽂지 말 것             (28) 꽂지 말 것
 (29) GPIO5   오른 홀 DO     (30) 비움
 (31) GPIO6   비움(홀2 예비) (32) GPIO12 오른 RPWM
 (33) GPIO13  오른 LPWM      (34) GND   IR
 (35) GPIO19  왼 LPWM        (36) GPIO16 왼 홀 DO
 (37) 비움                   (38) GPIO20 비움(홀2 예비)
 (39) 비움                   (40) GPIO21 왼 L_EN
