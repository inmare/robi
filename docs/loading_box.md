# 목표

적재함에서 받은 책을 자동으로 이동하는 로봇 만들기

# 구조

## 뼈대

- 20x20 알루미늄 프로파일로 가로·세로 프레임을 구성한다.
- 리프트용 연마봉과 리드스크루는 상·하단의 고정 프레임에 체결하고, 푸셔용 모터와 회전축은 상단 고정 프레임에 체결한다.
- 움직이는 리프트 아크릴판과 푸셔가 프레임·볼트 머리·배선에 닿지 않도록 고정부와 이동부를 분리한다.
- 아두이노, CNC 쉴드, 전원부는 적재 공간 밖의 별도 아크릴 장착판에 스페이서로 고정한다.

## 책 들어올리기

- 책을 받치는 280x280mm 아크릴판을 이동판으로 사용하며, 처짐 시험 결과에 따라 8mm 판 또는 5mm 판과 하부 보강대를 사용한다.
- 8mm 연마봉 2개를 이동판 앞쪽 좌우에 배치하고, 각 연마봉의 위·아래를 SK8 지지대로 프레임에 고정한다.
- 이동판에는 연마봉 하나당 LMK8UU 2개를 체결한다. 총 4개의 베어링이 판의 회전과 좌우 흔들림을 억제하면서 위아래 이동을 안내한다.
- 리드스크루는 이동판 뒤쪽 가운데에 배치하고, 리드스크루 너트를 이동판에 체결한다. 한쪽으로 치우친 구동점 때문에 판이 비틀리지 않도록 두 연마봉과 리드스크루의 중심을 삼각형으로 배치한다.
- 하단 NEMA17 스텝모터를 브래킷으로 고정하고 5mm-8mm 커플링으로 리드스크루에 연결한다. 모터가 회전하면 리드스크루 너트와 이동판이 함께 상승·하강한다.
- 리드스크루 상단은 KP08로 반경 방향 흔들림만 억제한다. KP08을 축 방향 하중 지지용으로 간주하지 않으며, 단기 시연에서는 리드스크루 하중과 모터 발열을 실제 책 무게로 시험한다.
- VL53L0X는 책 윗면과 상단 사이 거리를 측정해 정상 상승 위치를 결정한다.
- 상·하단 리미트 스위치는 VL53L0X가 잘못 측정하거나 배선이 끊어졌을 때 이동판이 프레임을 충돌하는 것을 막는 최종 한계 장치로 사용한다.
- 상승·하강 명령에는 최대 동작 시간을 두고, 시간 안에 거리 조건이나 리미트 스위치 입력이 들어오지 않으면 모터를 정지한다.

## 책 밀기

- 리프트가 목표 높이에 도달한 뒤에만 푸셔가 동작하도록 제어 순서를 제한한다.
- NEMA17 스텝모터를 상단 프레임에 고정하고, 5mm-8mm 커플링으로 8mm 회전축에 연결한다.
- 회전축 양쪽을 KP08 2개로 지지해 축이 휘거나 기어 맞물림 높이가 변하는 것을 줄인다.
- 같은 규격의 원형 기어 2개를 회전축에 고정한다. 두 기어의 이빨 위상을 맞춰 좌우 리니어 기어가 같은 거리만큼 움직이게 한다.
- 리니어 기어 2개는 하나의 푸셔 판에 체결한다. 원형 기어가 회전하면 두 리니어 기어와 푸셔 판이 함께 전진해 책의 넓은 면을 민다.
- 각 리니어 기어는 원형 기어 앞·뒤에 설치한 짧은 터널형 가이드를 통과한다. 가이드는 리니어 기어 몸통의 좌우와 아래를 지지하고, 이빨에는 닿지 않도록 여유를 둔다.
- 푸셔 전진·후진 끝에는 리미트 스위치를 설치한다. 전진 스위치가 눌리면 책 밀기를 멈추고, 후진 스위치가 눌리면 푸셔 원점 복귀를 완료한다.
- 푸셔에도 최대 동작 시간을 적용해 책 걸림, 기어 이탈 또는 센서 고장 시 계속 밀지 않도록 한다.

## 전원 및 제어 흐름

- 12V 5A 어댑터 출력은 5A 퓨즈와 주 전원 스위치를 거쳐 CNC 쉴드의 스텝모터 전원으로 공급한다.
- 같은 12V 입력을 5V 스텝다운 모듈로 낮춰 아두이노와 통신 모듈에 공급하며, 모터 전원과 로직 전원은 분기하되 GND는 공통으로 연결한다.
- A4988의 전류 제한은 KH42JM2-901과 17HS4401 정격에 맞춰 설정하고, 실제 구동 중 드라이버·모터 온도와 탈조 여부를 확인한다.
- 기본 동작 순서는 `대기 → 책 높이 측정 → 리프트 상승 → 상승 확인 → 푸셔 전진 → 책 배출 → 푸셔 복귀 → 리프트 복귀`로 구성한다.
- 각 단계는 이전 단계의 완료 신호가 있어야 다음 단계로 넘어가며, 리미트 스위치 충돌·시간 초과·통신 끊김이 발생하면 모든 스텝 펄스를 중지한다.

# AI

필수적으로 고쳐야 할 문제만 우선순위대로 나열하면:

1. 스텝모터용 12V 외부 전원이 없음
    - 아두이노 이외의 스텝모터용 고출력 전원은 반드시 필요함, 다만 그게 반드시 12V일 필요는 없음
    - 출력 12V DC, 용량 최소 5A, 정전압 방식
    - **필요한 부품**: DC 12V 5A 어댑터 5.5 2.1, DC 5.5 2.1 암잭 변환 젠더, 12V 5V 벅 컨버터(아두이노 전원 공급용)
2. 모터 정격전류와 A4988의 구동 가능 여부가 확인되지 않음
    - A4988도 안전하게 출력할 수 있는 전류에 한계가 있다는 뜻
    - KH~는 1.2A/상, 17H~는 1.7A/상, A4988은 방열판 사용시 1.2~1.5A 수준이 현실적
    - 가변저항을 조절해서 제한값을 해결할 수는 있지만 그렇지 못한 경우 더 좋은 드라이버가 필요함
    - **필요한 부품**: DRV8825(더 높은 전류용)
3. `KH42JM2-901`의 배선 방식과 A4988 호환 여부가 불확실함
    - 구동 가능, 다만 멀티미터로 코일쌍을 재확인 해야 함
4. 리드스크루 커플링이 없음
    - **필요한 부품**: 5mm 8mm 리드스크류 커플링
5. 리드스크루가 축 방향 하중을 직접 모터에 전달하는 구조
    - 스러스트 베어링과 샤프트 칼라를 넣어서 무게를 분산시키면 되긴하는데 일단 단기시연용이라 제외
6. 리드스크루가 한쪽에 치우쳐 있어 받침판이 기울거나 걸릴 가능성
7. 연마봉 하나만으로는 받침판의 회전과 비틀림을 충분히 막기 어려움
    - **필요한 부품**: 8mm 연마봉 (하나만 있음)
8. 연마봉 및 SC8UU의 정확한 개수와 배치가 확정되지 않음
    - 뒤쪽 가운데에 모터, 앞쪽 양 옆에 연마봉 2개 배치
9. 아크릴판의 강도와 베어링 체결 방식이 확정되지 않음
    - 베어링 자체는 존재하지만, 이걸 아크릴판에 고정하는 브래킷이 필요함
    - **필요한 부품**: LMK8UU 4개 (연마봉 하나당 2개, 수직형태의 베어링), 베어링을 고정할 더 긴 볼트, 와셔, 너트
10. 리프트 상단·하단 리미트 스위치가 없음
    - **필요한 부품**: 리미트 스위치 2개(하단, 상단용)
11. VL53L0X만으로 상승 정지를 판단하는 구조
    - 리미트 스위치를 추가해서 그에 대한 작성이 필요함
12. 양쪽 푸셔 모터가 서로 어긋날 수 있음
    - 모터는 하나만 두고, 축을 연결한 다음에 축에다 기어 2개를 고정해서 회전시키기
    - **필요한 부품**: 5mm 8mm 커플링, 8mm 축, KP08 2개(축 지지용), 8mm 샤프트 칼라 3~4개(기어 고정용)
13. 푸셔의 전진·후진 한계 감지 장치가 없음
    - **필요한 부품**: 리미트 스위치 2개(앞, 뒤용)
14. 모터 걸림이나 센서 고장 시 강제 정지 수단이 없음
15. 최대 책 무게와 리프트에 필요한 모터 토크가 계산되지 않음
16. 모터를 프로파일에 고정할 모터 브래킷이 설계되지 않음
    - **필요한 부품**: 모터를 고정하는 3d프린팅 부품 2개(바닥용, 푸셔용 하나씩), 고정용 나사 최소 8개
17. 연마봉의 상·하단을 고정할 샤프트 지지대가 없음
    - **필요한 부품**: SK8 연마봉 지지대 4개 (연마봉 2개, 위아래용)
18. 리드스크루의 상·하단 지지 및 축 방향 고정 방법이 정해지지 않음
    - 상하단지지는 언급되어있고, 하단지지는 모터 고정으로, 상단지지는 KP08로 해결하면 될듯?
    - **필요한 부품**: KP08 1~2개
19. 모터와 리드스크루의 중심축을 정확히 정렬할 방법이 없음
20. CNC 쉴드, 전원 장치, 센서와 배선을 프레임에 고정할 방법이 정해지지 않음
    - 단기시연이라 적당한데 두면 될 듯, 여유가 된다면 pcb에 구멍 뚫고, 장차판과 스페이서등으로 프로파일에 고정하기
21. 진동으로 볼트와 부품이 풀리지 않도록 하는 대책이 없음
    - 단기 시연할거라 제외
22. 각 부품의 장착 위치와 체결 구멍 치수가 확정되지 않음
    - 지금 Fusion을 사용해 대략적으로 설계중
23. 전원 및 퓨즈가 필요함
    - **필요한 부품**: 로커 스위치 DC 12V 10A 이상, 5A 퓨즈, 퓨즈 홀더
