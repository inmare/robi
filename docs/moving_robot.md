# 목표

적재함에서 받은 책을 자동으로 이동하는 로봇 만들기

# 구조

## 뼈대

- 20x20 알루미늄 프로파일로 상·하부 사각 프레임과 수직 기둥을 구성한다.
- 배터리와 모터 드라이버는 하부에 배치해 무게중심을 낮추고, 라이다는 프레임과 책에 시야가 가리지 않는 높이에 고정한다.
- 라즈베리 파이, ESP32-CAM, 전원 모듈과 배선은 별도 장착판에 스페이서·볼트로 고정해 진동 중 단락이나 커넥터 이탈을 방지한다.
- 모터 전원선과 센서·통신선은 가능한 한 떨어뜨려 배선하고, 프레임 모서리와 이동 부품에 쓸리지 않도록 묶는다.

## 책 적재함

- 하부 고정 아크릴판과 책을 받는 상부 이동 아크릴판 사이에 용수철 4개를 배치한다.
- 용수철을 에폭시만으로 붙이지 않고, 상·하단에 3D 프린팅한 받침컵을 볼트로 체결해 반복 압축과 측면 힘에도 위치가 변하지 않게 한다.
- 이동 아크릴판 양옆은 수직으로 설치한 서랍 레일에 브래킷으로 연결한다. 레일은 판의 좌우 회전과 기울어짐을 억제하고, 용수철은 책 무게에 따라 판을 아래로 이동시킨다.
- 네 용수철은 판 모서리에서 같은 거리에 배치하고, 책이 한쪽에 놓여도 레일이 걸리지 않도록 좌우 레일의 평행도와 높이를 맞춘다.
- 아크릴판은 5~8mm 두께를 사용한다. 5mm를 사용할 경우 아래쪽에 알루미늄 보강대를 추가하고, 최대 책 무게로 처짐과 레일 마찰을 시험한다.
- 책 투입 경로에는 IR 브레이크 빔 센서를 설치한다. 광선이 일정 시간 차단되면 책 한 권이 들어온 것으로 판단하되, 짧은 순간 차단은 진동이나 손의 통과로 보고 무시한다.

## 이동 및 주차

- 앞쪽 좌우의 JGA25-370 모터와 바퀴를 서로 독립적으로 구동하는 차동구동 방식을 사용한다. 두 바퀴를 같은 방향으로 돌리면 직진하고, 속도 차이나 반대 방향 회전으로 방향을 바꾼다.
- 뒤쪽은 중앙 볼캐스터 1개를 기본 구조로 사용해 네 점 지지에서 생기는 흔들림과 한쪽 구동 바퀴가 뜨는 현상을 줄인다.
- 포맥스 경사로의 시작점은 1인치 볼캐스터가 걸리지 않도록 완만하게 연결하고, 실제 책을 적재한 총중량으로 약 2~4° 경사 주행을 시험한다.
- 각 바퀴 옆에 네오디움 자석을 같은 간격으로 붙이고 홀 센서로 통과 횟수를 센다. 좌우 회전량 차이를 보정해 직진성을 높이되, 바퀴 미끄러짐이 있으므로 절대 위치 판단은 라이다와 주차 센서가 담당한다.
- X4 Pro 라이다 데이터는 라즈베리 파이에서 각도별 거리값으로 파싱한다. 전방 안전거리 안에 장애물이 들어오면 감속·정지하고, 좌우 여유 공간을 비교해 회피 방향을 정한다.
- 적재함 접근은 `라이다로 적재함 방향 탐색 → 저속 접근 → 반사 표식 또는 정해진 적재함 형상 확인 → 리미트 스위치 접촉` 순서로 수행한다.
- 반사 테이프는 근거리 표식 식별을 돕는 보조 수단으로 사용하고, 최종 정지 위치는 좌우 리미트 스위치가 모두 눌렸는지 확인해 결정한다. 한쪽만 눌리면 반대 바퀴를 천천히 움직여 자세를 맞춘다.
- 라이다만으로 적재함과 일반 장애물을 확실하게 구분하지 않고, 적재함의 고정된 형상·표식과 물리적 주차 가이드를 함께 사용한다.

## 전원 및 구동

- 65W 20000mAh 보조배터리의 USB-PD 출력은 ZY12PDN 트리거 모듈로 필요한 전압을 요청한다.
- 트리거 출력은 퓨즈와 주 전원 스위치 뒤에서 모터 전원과 로직 전원으로 분기한다.
- 모터 전원은 XL4016E1 스텝다운 모듈로 JGA25-370 정격에 맞춘 뒤 N7960 모터 드라이버 2개에 공급한다.
- 라즈베리 파이와 ESP32-CAM은 별도의 5V 5A 스텝다운 모듈에서 공급하고, 모터 계통과 로직 계통의 GND는 공통으로 연결한다.
- 각 모터 단자에는 0.1uF 세라믹 커패시터를 연결하고, 모터 드라이버 전원 입력 가까이에 2200uF 전해 커패시터를 연결해 브러시 노이즈와 출발 시 전압 강하를 줄인다.
- 주 전원 스위치와 별도로 모터 전원 차단 스위치를 두어 제어 프로그램이 멈춰도 구동부 전원을 물리적으로 끊을 수 있게 한다.
- 퓨즈 용량과 XL4016 출력 전압은 모터를 연결하기 전에 멀티미터로 확인하며, 라즈베리 파이에 보조배터리의 높은 전압을 직접 연결하지 않는다.

## 제어 및 안전 상태

- 라즈베리 파이가 라이다 처리, 경로 판단, 좌우 모터 명령과 중앙 센터 통신을 담당하고, ESP32-CAM은 보조 영상과 비상 정지 통신을 담당한다.
- 기본 상태는 `탐색 → 적재함 접근 → 저속 정렬 → 주차 완료 → 적재 대기 → 적재 완료 확인 → 출발 허가 대기 → 이동`으로 구성한다.
- 중앙 센터와는 `주차 완료 → 적재 요청 → 적재 완료 → 출발 허가` 순서로 메시지를 주고받고, 각 메시지에는 상태 번호를 넣어 중복 수신으로 같은 동작을 반복하지 않게 한다.
- 주행 중 중앙 센터 신호나 내부 제어 갱신이 정해진 시간 동안 끊기면 PWM 출력을 0으로 만들고 모터를 정지한다.
- 라이다 거리값 오류, 좌우 홀 센서 장시간 무응답, 리미트 스위치 입력 불일치가 발생하면 자동 동작을 중단하고 수동 확인 전까지 다시 출발하지 않는다.

# AI

모터가 없다는 문제는 삭제할 수 있지만, 추가한 `JGA370`과 기존 `JGA25용 브라켓`, `4mm 허브`의 규격 호환성은 새로 확인해야 합니다. 번호를 정리하면 다음과 같습니다.

1. ESP8266 하나로 라이다·Wi-Fi·모터를 모두 처리하기에는 안정성이 부족할 수 있음
   - 단순 모터 제어는 가능하지만 X4 Pro 데이터 처리까지 맡기기에는 메모리와 UART 여유가 적음
   - **필요한 부품**: 그냥 있는 라즈베리 파이 쓰기

2. 라이다만으로 정확한 주차 위치를 결정하기 어려울 수 있음
   - 적재함과 일반 장애물을 구분할 기준이 필요함
   - ToF 센서, 주차 표식 또는 물리적인 주차 가이드를 추가하는 방법을 검토해야 함
   - 반사테이프를 적재함에 붙여서 근거리까지 접근하게 하고, 리미트 스위치를 적재함쪽에 둔 다음에 입력을 감지하는 방식으로 미세한 조절
   - **필요한 부품**: 리미트 스위치 2개, 반사 테이프
3. JGA370 모터에 엔코더가 있는지 확인되지 않음
   - 현재 모터에 엔코더가 없어서 임의로 엔코더 비스무리한걸 만들어야 됨
   - 바퀴 옆에 자석을 동일한 간격으로 붙이고 홀 센서를 사용해서 바퀴가 얼마나 회전했는지 파악 가능
   - **필요한 부품**: 네오디움 자석 최소 8~16개(바퀴당 4~8개), 홀 센서 2개, 사포(자석 부착용)
4. JGA370과 기존 장착 부품의 규격 호환성이 확인되지 않음
   - 브라켓은 있지만 브라켓의 구멍이 지금있는 나사와 호환되지 않음
   - **필요한 부품**: M4 대형 와셔(가운데 구멍에 M4 볼트 넣기용)
5. 배터리 전압과 용량이 정해지지 않음
   - JGA370의 정격전압을 확인한 후 배터리를 선정해야 함
   - 모터 전원과 ESP32·라이다용 5V 전원을 분리해야 함
   - **필요한 부품**: 65W 30000mah 보조배터리, 20V PD 트리거, 20V 6V 벅 컨버터, 4A 퓨즈 여유분, 퓨즈 홀더 여유분
6. 모터 노이즈로 ESP32와 라이다가 재부팅될 수 있음
   - 모터 전류 변화로 전압 강하와 전기적 잡음이 발생할 수 있음
   - 전원 분리, 공통 GND, 커패시터와 적절한 배선이 필요함
   - **필요한 부품**: 0.1uF 세라믹 커패시터 (모터 고주파 잡음 흡수용), 1000~2200uF 전해 커패시터(모터 출발시 전류 보충용)
7. 아크릴판을 레일에 고정할 브라켓이 없음
   - L형 금속 브라켓 또는 3D 프린팅 어댑터가 필요함
   - 아크릴 균열 방지를 위해 큰 와셔와 고무 와셔를 사용해야 함
   - **필요한 부품**: L형 브래킷(직경 5mm 구멍 있어야 함), M4 일반 너트(최소 4개), M4 스텐 와셔 12mm(최소 8개)
8. 용수철을 에폭시만으로 고정하는 방식이 불안정함
   - 반복 압축과 측면 힘으로 접착 부위가 떨어질 수 있음
   - 상·하단에 원형 홈이나 기계식 고정구가 필요함
   -  용수철 받침컵을 설계한 다음에 바닥 아크릴판에 볼트로 고정하기
   - **필요한 부품**: 3D프린트로 뽑은 용수철 받침 컵(최소 8개), M4너트, M4 스텐 와셔
9. 용수철의 강도가 책 무게에 적합한지 확인되지 않음
   - 용수철 상수와 최대 압축 길이가 필요함
   - 최대 책 수량과 총중량을 정한 후 실제 압축 시험을 해야 함
10. 용수철 4개가 균일하게 압축되지 않을 수 있음
    - 책이 한쪽에 놓이면 아크릴판이 기울거나 레일에 걸릴 수 있음
    - 레일의 평행도와 아크릴판의 비틀림 강성을 확보해야 함
11. 서랍 레일을 수직으로 사용할 수 있는지 확인되지 않음
    - 수직 설치 시 유격, 마찰 또는 볼베어링 문제가 발생할 수 있음
    - 실제 방향과 하중으로 시험해야 함
12. 아크릴판의 두께와 강도가 정해지지 않음
    - 책 무게와 용수철의 집중하중으로 휘거나 깨질 수 있음
    - 5~8mm 이상을 검토하고 필요하면 알루미늄 보강대를 추가해야 함
13. JGA370이 경사로를 오를 수 있는지 확인되지 않음
    - 감속비, RPM과 출력 토크가 문서에 없음
    - 로봇 총중량, 바퀴 반지름 및 경사각을 기준으로 계산하고 시험해야 함
    - JGA25-370은 6V 176RPM, 감속비 약 1:35 제품이며 평지와 약 2~4°의 완만한 경사로를 목표로 실제 총중량 상태에서 시험해야 함.
14. 1인치 볼캐스터가 경사로에 걸릴 수 있음
    - 작은 볼캐스터는 경사 시작점과 판 이음매를 넘기 어려움
    - 경사로를 잘 설계해야 될 필요가 있음
15. 앞바퀴 2개와 뒤쪽 볼캐스터 2개 구조가 흔들릴 수 있음
    - 바닥이 고르지 않으면 구동 바퀴 하나가 들릴 수 있음
    - 뒤쪽 중앙 캐스터 하나를 다는 대신 배터리등을 아래쪽으로 배치해 무게중심을 아래쪽으로 낮출 필요가 있음
16. 비상 정지 및 통신 끊김 대책이 없음
    - 중앙 센터 신호가 일정 시간 없으면 자동 정지해야 함
    - 물리적인 비상 정지 스위치도 필요함
    - **필요한 부품**: 로커 스위치 DC 12V 10A 이상 2개
17. 책이 정상적으로 들어왔는지 확인하는 장치가 없음
    - 포토인터럽터, 레이저 차단 센서 또는 무게 센서를 검토해야 함
    - **필요한 부품**: IR Break Beam센서
18. 중앙 센터와 로봇의 통신 순서가 정해지지 않음
    - `주차 완료 → 적재 요청 → 적재 완료 → 출발 허가` 등의 상태를 정의해야 함
    - 중복 신호와 통신 실패 시 동작도 정해야 함
19. 전체 부품의 장착 위치와 배선 경로가 정해지지 않음
    - 프레임이나 책이 라이다 시야를 가리지 않아야 함
    - 배터리, ESP32 및 모터 드라이버를 진동에 견디도록 고정해야 함

## 주의사항

- 배터리~스위치 분기, 스위치 분기~모터는 awg18전선 사용
- XL4016, N7960은 열이 납니다. 파이·라이다 USB 바로 밑에 붙이지 마세요. 방열판이 있으면 세우고, 서로 맞대 두지 마세요.
- 2200uF는 N7960 전원 입력 바로 옆(수 cm). 멀리 두면 기동 시 전압이 떨어집니다. 극성 있습니다. −를 GND에.
- 0.1uF는 모터 단자 모터 몸 쪽에 가깝게. 드라이버까지 긴 선 끝보다 모터에 다는 게 노이즈에 낫습니다.
- 모터 두꺼운 선과 홀·PWM 가는 선은 같은 묶음으로 길게 가지 않기. 프로파일 반대쪽이나 몇 cm 띄우기.
