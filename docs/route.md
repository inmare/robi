# 지도 작성 후 경로 왕복

엔트리: `code_moving_robot/main.py`  
스택: `docs/moving_stack.md`

시작하면 **슬롯 4개** TUI가 뜬다. 각 슬롯은 이름·기록 시각과 함께 지도+경로를 가진다. 빈 슬롯이나 `n`으로 새 경로를 기록하고, 채워진 슬롯은 재생하거나 덮어쓴다.

재생(`r`)은 찍어 둔 점을 **끝까지 갔다가 같은 선으로 시작점**까지 돌아온다. 경로 중간이나 살짝 옆에 두고 켜도, 스캔으로 선 근처를 맞춘 뒤 그 지점부터 왕복의 나머지를 따른다. 막히면 후진 → 좌우 수색 → 옆 이동 → 맵에 없던 장애물을 기억하고 A*로 원래 경로의 앞쪽에 다시 붙는다.

ROS/Nav2 없음.

지도는 홀만 믿지 않는다. 스캔을 기존 벽에 맞춘 뒤에만 칸을 그린다 (스캔-투-맵 SLAM). 맞추지 못한 스캔은 버려서 벽이 원형으로 돌지 않게 한다. 재생 중에는 지도를 다시 그리지 않는다.

홀만으로 번진 옛 PGM은 지우고 다시 그린다. 슬롯은 `maps/slots/slot_N/` 이다.

```bash
rm -rf maps/slots
```

## 한 번만

```bash
cd code_moving_robot
uv pip install --python .venv/bin/python gpiozero
```

`robot/pins.py`의 `TRACK_M`을 좌우 바퀴 **접지 중심 사이** mm를 자로 재서 미터로 넣는다. 이 값이 틀리면 회전할 때 지도와 로봇 위치가 어긋난다.

라이다는 수평에 가깝게. 기울여 만든 지도는 윤곽용이고 경로용 최종 맵으로 쓰지 않는다.

## 실행

```bash
cd code_moving_robot
.venv/bin/python main.py
```

메뉴에서 슬롯을 고른 뒤, Enter, **그다음** 모터 6V를 켠다. SSH면 터미널이 포커스를 가진 채 키를 누른다.

### 시작 메뉴

| 입력 | 동작 |
|---|---|
| `1`~`4` | 슬롯. 비었으면 새 기록. 있으면 재생/덮어쓰기 |
| `n` | 새 경로. 기록 후 빈 슬롯(또는 덮어쓸 슬롯)과 이름을 묻는다 |
| `o` | 슬롯을 골라 덮어쓰기 기록 |
| `q` | 종료 |

채워진 슬롯에는 이름과 `YYYY-MM-DD HH:MM`이 보인다. 덮어쓰면 확인을 한 번 더 묻는다. 저장 때 이름을 정하고, 시각은 자동이다.

로봇은 **시작하려는 칸**에 둔다. 그 슬롯의 첫 실행이면 앞이 맵의 +x(처음 전진 방향)이게 맞춘다. 켠 위치가 (0,0), 그때 앞이 yaw 0이다.

저장 맵이 있는 슬롯이면 같은 칸에만 두면 된다. 앞 방향은 반대여도 된다. 시작 직후 라이다가 경로 선(옆 이탈 포함)을 보고 yaw를 맞춘다.

## 주행 키

| 키 | 동작 |
|---|---|
| `w` `s` | 전진 / 후진. 누르고 나면 유지, 멈출 때 스페이스 |
| `a` `d` | 제자리 좌/우회전 |
| 스페이스 | 바퀴 정지 |
| `↑` `↓` | 속도 업/다운. 가는 중에도 바로 반영. 재생 중에도 됨 |
| `k` | 경로 기록 on/off. `w` `e` 옆이 아니라 일부러 떨어뜨림. 도착 칸에서 끄면 지금 자리가 `G` |
| `1` | 지금 위치를 시작점으로 다시 기록 |
| `2` | 지금 위치를 경유점으로 수동 추가 |
| `3` | 지금 위치를 도착으로 하고 기록 종료 |
| `m` | ASCII 지도 + 지금 슬롯 저장. `S` 시작, `G` 도착, `R` 로봇 |
| `p` | 숫자 좌표 |
| `l` | 지금 스캔으로 경로 위·옆 위치를 다시 찾음. 중간에 두거나 제자리 회전 뒤 |
| `S` | 지금 슬롯에 저장 (`s`는 후진) |
| `r` | **왕복 재생.** 스캔으로 지금 점을 맞춘 뒤, 남은 길을 도착까지 가고 같은 선으로 시작점에 돌아온다. `G` 근처면 시작으로만 온다 |
| `t` 또는 아무 키 | 자율 중이면 수동으로 멈춤 |
| `q` | 주행 종료 후 슬롯 메뉴. 새 기록이면 슬롯·이름을 묻는다 |

시작점은 프로그램을 켠 자리가 기본이다. 보통 `1`은 안 눌러도 된다. 제자리에 서 있으면 점이 안 늘어난다. 간격은 `RECORD_DT`(1초), `RECORD_MIN_M`(0.25m).

## 권장 순서

1. `main.py`를 켠다. `n` 또는 빈 슬롯을 고른다.
2. `w`로 **시연할 길 그대로** 천천히 간다. `경로 n ...`이 찍힌다.
3. 도착 칸에서 `k` (또는 `3`). 기록이 끝나고 그 자리가 `G`.
4. `q`로 주행을 끝내고, 빈 슬롯과 이름을 넣는다. 시각은 자동.
5. 시작 칸(또는 경로 중간)에 두고 같은 슬롯을 고른 뒤 `1` 재생.
6. `r`. 찍혀 있는 선을 따라 `G`로 갔다가 시작으로 돌아온다.
7. 메뉴 `q`로 프로그램을 끝낸다.

`r`은 빵가루를 순서대로 갔다가 **역순으로 시작점**에 붙인다. 맵의 `#` 조각이 길을 막았다고 전체를 버리지 않는다. 로봇이 선에서 `REJOIN_OFF_M`(약 28cm) 이상 옆이면 A*로 선에 붙인 다음 나머지를 따른다.

자동 중 전방 장애물, 라이다 스캔이 `LIDAR_STALL_S`(1.2초) 끊김(바닥에 걸린 경우), 또는 경로 남은 거리가 `STALL_S`(3초) 동안 거의 안 줄면 **약 50cm 후진 → 좌우로 돌아 스캔을 넓힘 → 좌우 여유 확인 → 좁게 옆 이동 → 전방의 맵에 없던 히트와 맞은 앞을 가상 장애물로 남기고, 원래 경로의 앞쪽 점으로 A* 재연결**한다. 제자리 회전·SLAM 흔들림은 움직임으로 보지 않는다. 좌우가 둘 다 막혀도 재연결을 한 번 시도한다. 한 웨이포인트에서 연속 `RECOVER_MAX`(4)회를 넘기면 수동. 다음 점을 통과하면 횟수는 다시 0부터.

자동 중에는 자홍색으로 `왕복`/`복귀`, `점 i/n`, 지금 좌표, 다음 점, 남은 거리, 앞각을 찍는다. 중간에서 출발해도 남은 개수가 아니라 원래 번호다. 회복 중에는 노란 `[회복 ...]`. SSH TTY면 색, 파이프면 무색.

## 저장 파일

슬롯 `N` (1~4):

- `maps/slots/slot_N/meta.json` — 이름, 기록 시각
- `maps/slots/slot_N/map.bmp` — 윈도우에서 열리는 그림. scp는 이걸 쓴다
- `maps/slots/slot_N/map.pgm` — 격자
- `maps/slots/slot_N/map.txt` — `m`과 같은 ASCII
- `maps/slots/slot_N/route.json` — 시작·경유·도착·마지막 포즈

`m` 또는 `S`를 누르면 지금 슬롯에 바로 저장한다. `q` 때도 새 기록이면 슬롯을 고른다.

```bash
scp USER@파이IP:/여기/나온/절대경로/map.bmp .
```

문서의 `code_moving_robot/maps/...` 상대 경로는 홈이 아니면 실패한다. PGM은 윈도우 사진 앱이 못 연다. BMP를 연다.

옛 `route/route_run.py` 는 `maps/last_map.*` 한 세트만 쓴다. 새 시연은 `main.py` 슬롯을 쓴다.

## 한계

- 홀은 미끄러짐을 모른다. SLAM이 벽을 보고 yaw를 고친다. 빈 복도에서는 홀만 남는다.
- 후진·회전 부호는 **마지막 모터 명령**을 따른다. 손으로 밀면 좌표가 틀린다. 그때는 `l`.
- 라이다 기울기·흔들림은 벽을 늘리거나 바닥에 찍는다.
- 재실행 맞춤은 경로 선 주변(`ROUTE_LATERAL_M` 약 55cm)에서 한다. 전혀 다른 칸에 두면 실패한다.
- 좌우가 뒤집힌 맵이면 `robot/pins.py`의 `LIDAR_ANGLE_SIGN`을 `+1`로 바꾼다.
- 바닥 장애물은 스캔 높이에 없어서 맵에 안 남는다. 라이다가 걸리거나 정체되면 후진·수색·우회한다. 양쪽이 좁고 A*도 실패하면 수동.
- 적재함과의 **세밀 주차**는 이 왕복의 시작 좌표만으로 하지 않는다. 함 표식·리미트는 이후.
