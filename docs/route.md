# 지도 작성 후 경로 이동

엔트리: `code_moving_robot/route/route_run.py`  
스택: `docs/moving_stack.md`

로봇을 **직접 천천히 몰면서** 지도를 쌓고, 그 자리에서 시작·경유·도착을 찍은 다음 `r`로 따라가게 한다. ROS/Nav2 없음.

## 한 번만

```bash
cd code_moving_robot
uv pip install --python .venv/bin/python gpiozero
```

`robot/pins.py`의 `TRACK_M`을 좌우 바퀴 **접지 중심 사이** mm를 자로 재서 미터로 넣는다. 이 값이 틀리면 회전할 때 지도와 로봇 위치가 어긋난다.

라이다는 수평에 가깝게. 기울여 만든 지도는 윤곽용이고 경로용 최종 맵으로 쓰지 않는다.

## 실행

로봇을 **시작하려는 칸**에 두고, 앞이 맵의 +x(처음 전진 방향)이게 맞춘다. 켠 위치가 (0,0), 그때 앞이 yaw 0이다.

```bash
cd code_moving_robot
.venv/bin/python route/route_run.py
```

글이 나온 뒤 Enter, **그다음** 모터 6V를 켠다. SSH면 터미널이 포커스를 가진 채 키를 누른다. Enter를 칠 필요 없다.

## 키

| 키 | 동작 |
|---|---|
| `w` `s` | 전진 / 후진. 누르고 나면 유지, 멈출 때 스페이스 |
| `a` `d` | 제자리 좌/우회전 |
| 스페이스 | 바퀴 정지 |
| `+` `-` | 수동 속도 |
| `1` | 지금 위치를 시작점으로 다시 기록 |
| `2` | 지금 위치를 경유점으로 추가 |
| `3` | 지금 위치를 도착점으로 기록 |
| `m` | ASCII 지도. `S` 시작, `1`… 경유, `G` 도착, `R` 로봇 |
| `p` | 숫자 좌표 |
| `s` | `maps/last_map.pgm`, `maps/last_route.json` |
| `r` | 자율주행. 아직 안 온 점(시작→경유→도착)을 A*로 이어서 따라감 |
| `t` 또는 아무 키 | 자율 중이면 수동으로 멈춤 |
| `q` | 종료. 라이다 DTR 정지, 지도 저장 |

시작점은 프로그램을 켠 자리가 기본이다. 보통 `1`은 안 눌러도 된다.

## 권장 순서

1. 시작 칸에 두고 실행한다.
2. `w` `a` `d`로 **천천히** 방을 돈다. 홀이 위치를 적분하고, 라이다가 그 포즈에 벽을 쌓는다. 미끄러지면 지도가 이중으로 나온다. 급회전하지 않는다.
3. 지나고 싶은 칸에서 `2`. 여러 번 가능.
4. 도착 칸에서 `3`.
5. `m`으로 벽(`#`)과 `S`/`G`가 보이는지 확인한다.
6. 로봇을 시작 근처로 몰고 간다 (이미 시작에 있으면 생략).
7. `r`. 전방 `FRONT_STOP_M`(기본 0.35m) 안에 점이 있으면 멈추고 수동이 된다.
8. `q`로 끝낸다.

A*는 벽으로 본 칸을 로봇 반지름만큼 부풀려 피한다. 길이 안 나오면 직진으로 다음 점만 잇는다. 빈 칸을 충분히 돌아다니지 않으면 벽에 붙인 점이 막힌다. 그때는 그 칸을 더 비우며 다시 그린다.

## 저장 파일

- `maps/last_map.pgm` — 격자 그림
- `maps/last_route.json` — 시작·경유·도착·마지막 포즈

SSH에서는 `m`의 ASCII가 지도다. PGM은 PC로 복사한다. `docs/lidar.md`.

## 한계

- 홀은 미끄러짐을 모른다. 긴 구간일수록 도착이 빗나간다. 천천히, 짧은 경유를 여러 개.
- 후진·회전 부호는 **마지막 모터 명령**을 따른다. 손으로 밀면 좌표가 틀린다.
- 라이다 기울기·흔들림은 벽을 늘리거나 바닥에 찍는다.
- Autonomy는 저장 맵 + 홀 추종이다. 닫힌 루프 SLAM이 아니다.
